# Security Policy

NEXUS OS is experimental software. It has not undergone a formal security audit
and should not be used to protect critical systems or sensitive data.

Do not publish exploitable vulnerability details in public issues. Contact the
maintainer privately using a contact method listed on the GitHub profile.
Include the affected version, impact, and reproduction steps. Never include
passwords, tokens, or private keys.

The local AI service should remain bound to localhost unless separately secured.
