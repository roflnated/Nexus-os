# NEXUS OS Roadmap

Roadmap items are goals, not promises or completed features.

## Current — Prototype
- [x] Minimal desktop prototype
- [x] Startup splash
- [x] CPU/RAM/storage overview
- [x] Ollama localhost chat
- [ ] Runtime testing on Fedora hardware
- [ ] Screenshots and install walkthrough

## Next — 1.2
- [ ] Detect Ollama availability and installed models
- [ ] Save preferences and selected model
- [ ] Conversation clear/export controls
- [ ] NVIDIA GPU telemetry where supported
- [ ] Accessibility and keyboard navigation review
- [ ] Automated tests

## Later — 2.0
- [ ] RPM/Flatpak packaging
- [ ] Reproducible Fedora-based image
- [ ] Update and rollback strategy
- [ ] Recovery media and signed releases

## Non-goals for early releases
- Custom kernel
- Automatic CPU/GPU overclocking
- AI-issued privileged root commands
- Mandatory cloud AI or telemetry
